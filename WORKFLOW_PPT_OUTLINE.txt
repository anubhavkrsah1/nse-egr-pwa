SLIDE 2: WHAT IS EGR?
────────────────────
Bullet Points:
• Electronic Gold Receipt — Dematerialized gold ownership
• NSE Good Delivery Standard — 99.5% to 99.9% purity
• 14 denominations (1mg to 1kg) in 2 purities (995 & 999)
• Tradeable on NSE like securities
• NSDL regulated, SEBI compliant
• Monthly vaulting + insurance (automatic deduction)
• Can be extinguished anytime for physical gold release

SLIDE 6: DETAILED WORKFLOW — PHASE 1 & 2
─────────────────────────────────────────
Phase 1: Collection (Day 1)
  • Depositor submits KYC (AADHAAR + PAN or PAN + CIN + GSTIN)
  • Fills Form 45 (deposit request)
  • Signs Letter of Indemnity
  • Sequel picks up gold (if <50km serviceable)
  • Photo proof + AWB generated
  • Temporary receipt issued

Phase 2: Assay (Day 2-3)
  • Refiner receives gold
  • Weighs & assays purity
  • If <95% → reject & return
  • If ≥95% → approve & generate Packing List
  • Assign denominations (10g, 100g, 1kg, etc.)
  • Issue assay certificate

Cards: Light blue background for each phase


SLIDE 7: DETAILED WORKFLOW — PHASE 3 & 4
─────────────────────────────────────────
Phase 3: Refining (Day 3-5, if needed)
  • If purity 92-95% → Heat treat
  • Parker Precious Metals / Augmont / GGC
  • Output: 99.5% or 99.9% pure
  • Assign bar numbers (>100g)
  • Issue refined gold certificate

Phase 4: Vaulting (Day 5-7)
  • Vault Manager receives bars
  • Physical verification:
    - Weight check
    - Bar number matching
    - Aadhaar verification
  • Store in high-security locker
  • Generate Vault Acceptance Certificate

Cards: Light orange background


SLIDE 8: DETAILED WORKFLOW — PHASE 5 & 6
─────────────────────────────────────────
Phase 5: DP Entry (Day 7-8)
  • DP logs into eDPAM system
  • Enters Deposit Request Number (DRN)
  • Credits ISIN units to demat account
  • Example: 24g → 2×GOLD10G999 + 4×GOLD1G999
  • Sends SMS/email confirmation
  • Margin blocked (non-tradeable for 1 day)

Phase 6: NSDL Registration (Day 8-10)
  • NSDL verifies KYC
  • Approves denomination
  • Registers EGR in master registry
  • ISIN goes LIVE
  • Now tradeable on NSE
  • Monthly charges auto-deduct

Cards: Light purple background


SLIDE 9: NSDL CHECKPOINT VALIDATION
───────────────────────────────────
3 Critical Checkpoints:

[Checkpoint 1] AFTER Form 45
  ✓ PAN verified in NSDL master
  ✓ AADHAAR verified
  ✓ No duplicate KYC
  └→ If fail: Reject email + SMS

[Checkpoint 2] AFTER Assay
  ✓ Purity ≥ 95.0%?
  ✓ Weight certified
  ✓ Bar numbers unique
  └→ If fail: Hold, request resample

[Checkpoint 3] BEFORE LIVE
  ✓ Demat account limit OK?
  ✓ DP balance sufficient?
  ✓ No existing duplicate ISINs
  └→ If fail: Queue for next day

SLIDE 13: EXTINGUISH FLOW
─────────────────────────
Irreversible Process (⚠️ Cannot undo)

Start → Depositor requests extinguish

  ↓
Calculate GST:
  Gold value: 24g × ₹7,000 = ₹168,000
  GST 3%:                  ₹5,040

  ↓
Depositor pays GST (₹5,040)

  ↓
Vault releases gold to Refiner

  ↓
Refiner ships to:
  • Depositor's address, OR
  • Collection centre

  ↓
NSDL marks EGR as EXTINGUISHED

  ↓
✅ FINAL (No recovery possible)

Color warning: Red background for "Irreversible"


SLIDE 14: ERROR RECOVERY
────────────────────────
Common Issues & Resolution:

❌ ISSUE 1: Purity < 95%
  └ Action: Send to resampling
  └ If still fail: Return to depositor
  └ Refund: All charges except refining

❌ ISSUE 2: Bar Number Mismatch
  └ Action: Audit trail initiated
  └ Vault rejects batch
  └ Hold gold, contact depositor

❌ ISSUE 3: DRN Pending >7 Days
  └ Action: NSE escalates to DP
  └ SMS sent to depositor
  └ Refund collection charges if >14 days

❌ ISSUE 4: Monthly Charges Not Paid
  └ Action: EGR frozen (frozen icon 🔒)
  └ Cannot trade
  └ Auto-unfreeze when paid

Color: Orange boxes for each issue
